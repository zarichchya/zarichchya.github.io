The slideshow used to be built by scanning public/slider/ in PHP (Application_Model_Photos::FirstPageImageSlider); Jekyll enumerates the same directory at build time instead. The crossfade itself is pure CSS: every image shares one @keyframes loop the length of a full rotation (slide_count * slide_seconds), each offset via its own animation-delay so they take turns. A negative delay is normal here -- it means "this image's clock already started that many seconds ago", which is what lets the very first image show at full opacity immediately instead of fading in on page load. Because the loop length and offsets depend on how many photos are actually in slider/, the percentages have to be computed here rather than hardcoded in template.css. {%- endcomment -%} {%- assign slides = site.static_files | where_exp: "f", "f.path contains '/slider/'" %} {%- assign slide_seconds = 5 %} {%- assign fade_seconds = 1 %} {%- assign slide_count = slides.size %} {%- assign total_seconds = slide_count | times: slide_seconds %}
